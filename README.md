# Harsh Gupta — Portfolio

A single-page portfolio built with Next.js App Router and Tailwind CSS.

## Updating content

- Add source and live projects in `data/projects.ts`.
- Add certificates in `data/certificates.ts`.
- Edit profile and experience copy in `app/page.tsx`.
- Replace `public/harsh-gupta-resume.pdf` when the résumé changes.

## Development

```bash
pnpm dev
```

## Production

```bash
pnpm build
```

Pushes to `main` can be connected to Vercel for automatic deployment.
